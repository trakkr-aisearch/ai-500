# Examples

These snippets can be run from the repository root or from this directory. They assume `pandas` is installed; `plot_top_20.py` also requires `matplotlib`.

- `plot_top_20.py` - plot the top 20 brands by AI visibility score.
- `month_over_month_rank_changes.py` - compare rank movement between the two latest monthly snapshots.
- `filter_by_sector.py` - filter the latest snapshot by sector.
