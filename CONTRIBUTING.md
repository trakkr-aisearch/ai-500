# Contributing

Issues are welcome for data quality questions, schema changes, documentation fixes, and reproducibility problems.

Pull requests are welcome for repository tooling, examples, documentation, and workflow improvements. Please keep changes focused on the public dataset and avoid adding customer-specific data, internal identifiers, raw prompt logs, private scoring details, pricing material, or product marketing copy.

For data corrections, include the snapshot month, affected `brand_id`, the field in question, and a short public source or rationale when possible.
